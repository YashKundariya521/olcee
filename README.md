# olcee
This repository contains the frontend code for Olcee International, a global manufacturer and exporter of industrial and eco-consumer products. The website is built to showcase Olcee’s multi-category product lines with equal prominence, reflect its “Make in India for the World” mission, and offer multilingual accessibility.
🌐 Live Features
	•	Responsive HTML/CSS structure with semantic layout
	•	Hero banner with mission-focused branding
	•	Sectioned design: About, Products, Contact
	•	Product line branding integrated (EcoServe®, Writeon®, Flexifoil®, BubbleX®, ScrubbPro®)
	•	Language selector for Google Translate integration
	•	Clean, scalable structure for future React or CMS migration

⸻

🚀 Technologies Used
	•	HTML5 / CSS3
	•	Google Fonts (Inter)
	•	Semantic layout + grid system
	•	Mobile-friendly design principles
